# Security Policy

## What this app stores

- Optional manual session cookie in `%USERPROFILE%\.cursor_widget_config.json`
- Reads Cursor IDE auth from local `state.vscdb` (read-only)

Never commit that config file, paste tokens into issues, or include them in screenshots/logs.

## Reporting a vulnerability

Open a private security advisory on GitHub if the repo supports it, or contact the maintainer.
Do not post live session tokens publicly.
